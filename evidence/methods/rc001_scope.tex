\paragraph{A retained numerical discrepancy.}
The primary V6 decision/target-rich report gives zero-cost R1 normalized
regret \nval{v6.regret_primary}. The separately reported full-image
utility-rescoring rows give \nval{v6.regret_sensitivity}. These are
the two source values recorded as RC-001. The main decision table and the
sensitivity table use their own source roles. The cause of the discrepancy
is not established here; the values are not averaged, repaired or silently
substituted. Display rounding can make them look equal, which is why the
exact values are retained in this note and the source data.
