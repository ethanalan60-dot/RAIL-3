# Release snapshot provenance

This public repository is a curated release snapshot derived from a private
research repository. Its Git history begins at public release time and does not
represent the chronology of the underlying experiments. Historical experiment
identities and frozen scientific records are documented separately and are not
replaced by this public commit history.

Version **v0.1.0** retains the scientific source/evidence selection established
at research commit `e08e1bd30747e01fa0237a3d87c3dba09d00c2f0`, with the bounded
engineering closure recorded at `3452b1f0d260ad1980c4761506a6a38fa6933a9e`.
These are provenance identities, not promises of access to private Git objects.
The release's actual commit/tag time records publication preparation, never a
retroactive experimental freeze, training event or first-GT timestamp.

The local release-preparation commit/tag identifies these contents. Its
existence alone does not certify that GitHub publication has completed; the
target repository and release provide the remote publication record.

## File and source identity

`SOURCE_TO_RELEASE.json` distinguishes exact source copies, bounded scientific
excerpts, location adapters and new release-use documents. Seven named historical
scripts/configurations are exact byte recoveries from explicitly bound commits;
individual source commit/blob/SHA/bytes and authority selectors remain in that
map. This establishes their per-file identity, not every original launch-lock,
historical test or runtime dependency. A source path containing an old stage,
audit or handoff name is an identity reference; it does not redistribute that
operational file or authorize following it outside this snapshot.

`evidence/source_map.json` binds all 19 tables and 12 figure identities, their
metrics/denominators, feature/model identities, roles and availability. An absent
source remains absent even when its digest is known. Public summaries do not
replace prediction arrays, scalers, checkpoints or panel/fold payloads.

Four code/configuration files retain the earlier ten location-only substitutions;
two saved metadata files retain exact host-location-token substitutions.
`docs/path_transformations.json` preserves their scope. Scientific AST/JSON
content and historical Git/checkpoint identities were not changed. New release
hashes are release-copy identities and cannot satisfy an original identity gate
by substituting this public commit. The engineering adapter has its own filename,
uses no original scientific launch mode, and reports historical verification as
NOT_PERFORMED. Its successful lexical checks do not establish scientific readiness.

The allowlist is `RELEASE_FILES.json`; `SHA256SUMS` additionally binds that
manifest and excludes itself. Checksums prove consistency with this supplied
snapshot, not independent signatures or scientific validity. No research `.git`,
raw payload, private operational report, environment, dependency wheel or local
build is included. Third-party/reference/photographic files remain excluded.
